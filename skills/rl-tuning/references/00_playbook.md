# 实验选择与执行

## 先算离目标还有多少秒

绑定实际可用父配置与控制 run。对每个计分步记实际 tokens N、设备数 D 和 wall W。对于目标 T，该步的参考 wall 上限为 N/(D×T)，待省时间为 W−N/(D×T)。固定卡数时，平均待省时间是以窗口聚合达标所需的平均降幅。逐步算术均值协议要用各步预计 wall 重算总分。只掌握相位均值时，将秒数预算标为估计。工作负载、计分边界或语义变化时，重新确定可比对照。

把每个候选分为可单独够到目标、可与其他候选补齐缺口、仅负责判别机制。先用乐观上界筛掉无法完成预定任务的实验。距离目标还有 19 秒时，一个暴露时间至多 10 秒的候选只能作补位。评估补位时写出可验证的剩余来源。

## 核对基线实际在跑什么

按项目栈确认框架、镜像、代码提交与补丁、拓扑和角色分配、实际解析配置和 worker 环境。对准备修改的功能逐项区分「配置声明」「组件消费」「运行时命中」。例如 FSDP2 配置键未必被 Megatron 路径消费，融合受入口、dtype、shape 和设备实现影响。证据可以来自实际构造类、算子轨迹、二进制或首个运行回执。记录未生效和待核查条目。采两条代表性时间轴，按计分步标出暴露在关键路径上的阶段和留白。

按同一执行图和窗口记阶段账。每项填写角色、执行位置、实测时间、时间并集、候选实际作用的区间、可消除上界、预计新增开销和证据。用暴露区间加覆盖关系对账整步 wall。通信按实际 group 和调用节拍归属到 DP、TP/SP 或其他域，再给旋钮计预算。累计通信、调用次数和 host 阻塞可提示查哪段。归因未辨清的差额留在待证栏。考虑瓶颈转移、排队和新开销后才给出预计净值。

## 把瓶颈变成实验

对每个候选写清父配置、可分辨的假设、变更、预期变化及可证伪观察、端到端收益区间、机时和失败后的动作。先按硬约束和目标缺口筛选，再比较「结果会不会改变下一步」与成本。可用乐观上界判断一条线够不够弥补缺口。等待、重叠和已量到的总耗时分别记账。

对每个待裁决问题写两个合理解释及可区分的观察。例如 gen 慢可能是长 prompt 下 token cap 压缩有效批，也可能是推理完成后下游服务未唤醒。静态检查先核配置和容量，最小集成用实际生产者、路由、消费者和必要阶段状态完成一次真实交换。分池时同时核对唤醒、首次完成请求与代表性长 prompt 的持续供给。单独测短样本可以定位接线，容量判定使用目标长度。

| 现状 | 优先取证 | 观察后的动作 |
|---|---|---|
| 有两个竞争根因 | 用现有计时和配置找只改变其中一项的差分 | 判别不了时再考虑短探针 |
| 预测收益低于噪声 | 同机重放或增加有效计分窗口 | 扩窗仍难区分时标灰区，比较机会成本 |
| 组件微基准有收益 | 接口冒烟、真实固定批或单步集成 | 确认加载路径、语义与下游边界后再计价 |
| 两个旋钮争用 HBM 或同段时间 | 先做独立主效应，再按影响面选择组合臂 | 在同父同窗口重新验收组合 |

成本低且判别力足够时，优先用静态核对、已有日志、固定批、最小接口探针。若只有集成端可观察目标，写明直接跑端到端的理由和预定终止条件。紧预算用短跑筛选，按项目要求保留独立重复和发布窗口。

设计对照时记录两臂实际生效的 profiler/tracer、参数、环境和执行顺序。已有材料能表明某项混杂时，先报告观测差，暂停单因素归因。下一次验证只保留可区分该假设的差异。

在实验卡预先登记通过、有效阴性或灰区、无效三个出口。每个出口写下会保留哪个父配置、是否值得扩窗、需要补什么证据。若候选实现改变执行图，例如新增前向和反向复用，把原实验覆盖范围与新实现新增的环节并列。重开时记录原反例、改变的前提及新对照。原有质量门继续按项目合同判定。

## 发车与收口

有执行授权时，先确认资源、队列占位、依赖、输出归属与采样健康。参数覆盖与实际配置树对账，明确新增或覆盖，检查解析值和 worker 启动路径。跨世代的门检、握手与终态信号按运行 ID 写入各自输出。工具提示和累计日志可供核查，以本轮的实际解析值、健康快照和状态信号做决定。对同一组共享资源使用所有链都认可的独占预留或互斥，从最后一次门检前持有到本轮所属资源确认释放。给重试独立标识并记录触发原因和上限。集成跨过权重桥或服务接口时，先验证生产者到真实消费者的最小数据交换。

发车后在首个应命中的位置核验运行标记和相关 rank。监控按实验类型锚定本轮阶段进展、实际退出和产物。端到端训练核对计分步，接口或命中探针核对其预登记回执。按实际热身长度设检查点和截止时间，出现致命错误或超过失活窗口即按登记条件告警并处置。收口交叉检查实际退出、期望产物、记录窗口和采样覆盖，只处理本次作业归属的资源。

## 判收后重排队列

冻结每个候选的工作量、时间口径和语义。用共同父配置与组合配置直接比较。在需要判断交互时，可考虑 A、B、A+B 对同一个控制的四臂设计。若成本限制只验证出组合结果，就把归因粒度限定在组合。报告同时保留已验证净收益、拟验证候选和理论上限。

每次有效回执后更新实验队列。有同窗整步过门且关键约束满足时，按预登记条件晋级或更新基线。局部命中但整步持平时，下调本轮可兑现收益，按工程价值另判是否保留。质量或资源门失败时记下测得的速度和阻塞项，保持可用父配置。无效窗口只回填失败边界及诊断线索。对选定父配置按实际负载重算缺口，并重估相关候选的净值和重叠，登记升序、降序、暂缓或归档的原因。
