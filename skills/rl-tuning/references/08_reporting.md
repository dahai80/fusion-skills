# 目录、交接与技能迭代

用 RL_TUNING_ROOT 下的项目材料与技能分离。每轮统一组装 00_brief（目标/窗口/阈值/机时）、10_plan（预测与实验顺序）、20_runs（ID、配置快照或位置、终态、采样和日志）、30_analysis（对照、归因、裁决）、90_report（结论、边界、冻结点）、99_retro（预测误差、浪费、改进）。模板见 [轮次](../templates/campaign.md) 和 [实验卡](../templates/experiment.md)。工作较小时可用索引链接分段，交接入口和关键信息仍保留。

- README 给人读的总览，台账给 Agent 按实验 ID、现场别名和状态定位。沿 experiment_id → run_id → step/score → evidence 回查。口径和来源不同的读数分别保存。本工作区按[正式数据标准](../references/experiment-data-standard.md)到项目数据根内的 `data/experiments/id-register.tsv`取号。按 record_path 查主表，用 source_run_id 去现场找日志。历史回填按来源范围查重，同名记录证据有冲突时保留多条来源和待核项。
- 一个 experiment_id 对应可判定的假设。每次运行或产生独立运行标识的暂存尝试进入运行清单，用 attempt 和终态区分相对次序、种类与是否启动。历史别名和组合计划原样保存并注明。登记表便于查找，原始日志、产物、裁决是验证依据。
- 可检索证据写相对项目路径与行号，或远端节点、绝对路径、时间窗、owner 与哈希。指明原始读数、项目汇总或推导。镜像收录和内容核验分别标记。采集数据大时登记位置，按需提取。
- 报告带实验 ID、父配置、各验收维度、收益范围、冻结产物与下一次动手的触发条件。裁决变更保留旧口径、原判、变更来源、新口径和复判，测量值保持原样。
- 历史材料按来源线、别名和记录层级登记。遍历发生超时、分页中断或缺少权限时，将扫描范围和失败位置写明，再分段查证。提出「没有某路线」前核对易漏的团队目录、别名、源索引和终态。覆盖数量注明分母及粒度。

## RSI

将预测和实际对齐，记录错因是观测、机制、实验设计、运行状态还是判据失配。为候选规则登记证据 ID、适用条件、反例和可证伪观察。候选规则应说明会改变哪个决策，重复本来就正确的动作时优先补例子。

用相同的、未泄露预期答案的历史题面回放旧版和候选版。把行为检查与文档是否存在的检查分开。增加一个可能误拒的反例，优先在首个新的真实轮次验证迁移性。晋升时注明来源、覆盖条件、回归结果和版本，保留可退回的上一版。冲突用 supersedes 指明具体规则，版本记录保留原判证据。

规则状态可记候选、回放后试用、真实轮次验证、撤回。在首次适用的新轮次，记录规则改变的实验排序或门检、预测与实测差、可量化的机时及反例覆盖。若实际反馈推翻原条件，先标影响范围，再收窄或撤回规则并更新回归。编写者人工走查、独立 Agent 表现与真实轮次迁移各有独立记录。
