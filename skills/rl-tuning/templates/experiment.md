# 实验卡

从项目数据根内的 `data/experiments/id-register.tsv`取实验号。立项写 RL-EXP，准备提交时再取所属 RL-RUN。现场别名另存 source_run_id。[字段标准](../references/experiment-data-standard.md)

| 字段 | 登记值 |
|---|---|
| 实验 ID / 来源范围 / 历史别名 / 判据版本 | ___ |
| 父实验与生效配置指纹 / 实际对照 baseline_run_id | ___ |
| 待裁决问题 / 竞争解释 / 区分两者的观察 | ___ |
| 变更 / 保持项 / RL 训练语义 | ___ |
| 当前目标差距 / 暴露路径与重叠 / 可移除上界 / 预估净值 | ___ |
| 最小可用路径（实际生产者、消费者与生命周期） / 命中回执 | ___ |
| 实验臂、控制臂、臂序、计分窗口、噪声及采集配置 | ___ |
| 机时预算 / 首进展检查点 / 停线条件 / 期望产物 | ___ |
| 完整性 / 主指标 / 机制 / 质量 / 语义 / 余量 / 发布各项目门 | ___ |
| 预登记分支（通过 / 阴性或灰区 / 无效）及各自下一步 | ___ |
| 实际运行 ID、来源标识、退出、步数、产物 / 计分 ID 和证据位置 | ___ |
| 实测差、归因边界和分项判定 / 调整判据的授权与生效范围 | ___ |
| 更新后的父配置、秒数缺口与队列 | ___ |
| 若重开历史支路，填原反例、改变的前提和重开触发条件 | ___ |
