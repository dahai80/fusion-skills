范围单机 8 卡加速器（4 卡训练 + 4 卡采样，异步），7B 语言模型，batch 64 / 32，学习率 1e-6（本页为虚构示例数据，仅演示版式） 对比对象上一轮（第 1 轮）与本轮（第 2 轮），均为正式训练 200 步，数据、训练参数、启动脚本相同 统计口径耗时、吞吐、利用率取第 3 步之后的中位数；单卡训练吞吐 = 每步 token 数 ÷ 4 ÷ 更新耗时，加权吞吐 = 全程 token 数 ÷ 4 ÷ 全程更新耗时
在上一轮基础上再做五项实现层优化，训练参数不变：单卡训练吞吐 3,100 → 7,400 tok/s（2.4 倍），算力利用率 11.2% → 26.8%，整轮 200 步 2.1 → 1.0 小时；训练奖励和一致性指标与上一轮重合。测试集准确率待评测。

30 步实测；显存 38 → 34 GB
②输出层只计算回答位置损失只需要回答 token 的概率，提示位置不再做词表投影，回答位置的数值不变。
③重复输入去重同一提示的多条采样共享相同输入，只编码一次、按位置复用，特征不变。约 5,200 → 7,400　1.4 倍
正式训练 200 步，三项合并测量
显存 34 → 43 GB
④均衡分卡按 token 量把样本均衡分到各训练卡。通用的负载均衡，只调顺序，不改变参与训练的样本。
⑤按显存预算放开重计算重计算用重复一次前向换显存；在显存预算内对部分层保留中间结果，梯度数值不变。
保持不变batch、学习率、数据、奖励、4+4 卡、200 步、启动脚本。试过未采用前缀缓存、长度重排、全关重计算。
