# caveman-compressor

**Kind**: plugin · **Category**: code · **Source module**: `fusion-plugins-ecosystem`

Context compaction plugin; saves tokens on long sessions

上下文压缩插件，长会话省 token

## Install

Installable package pinned in `registry.json` (schema v2 `artifacts`):
`caveman_compressor-v0.12.0-any-any.tar.gz` from the unified release
[`registry-artifacts`](https://github.com/dahai80/fusion-skills/releases/tag/registry-artifacts),
sha256-verified by consumers on install. Install and updates also work inside
the fusion Shell (`fusion-web-shell`); the site marketplace page maps to this
document.

## Source

Implementation lives in the `fusion-plugins-ecosystem` module of the fusion
monorepo; packaging and pins via `scripts/publish_artifacts.py` there.
