# fusion-doc-excel-report

**Kind**: plugin · **Category**: office · **Source module**: `fusion-doc`

Upload spreadsheets to generate financial reports with template rendering and multi-sheet rollup

上传 Excel 自动生成财务报表，支持模板渲染与多 sheet 汇总

## Install

Installation and updates are managed inside the fusion Shell
(`fusion-web-shell`); the site marketplace page maps to this document.

## Source

Implementation lives in the `fusion-doc` module of the fusion monorepo.
