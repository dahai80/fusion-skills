# fusion-agent-studio

**Kind**: app (host/consumer) · **Source repo**: `dahai80/fusion-agent-studio`

Agent studio: build, debug and run local agents.

Agent 工作室：构建、调试和运行本地智能体。

## Install

Download the archive for your platform from the
[releases page](https://github.com/dahai80/fusion-agent-studio/releases) and install locally.
Host apps are consumers of the plugin/connector/skill catalog, not entries of
it — they read `registry.json` and install entries on their own.
