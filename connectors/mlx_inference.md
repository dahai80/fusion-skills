## Install

Installable package pinned in `registry.json` (schema v2 `artifacts`):
`mlx_inference-v0.12.0-any-any.tar.gz` from the unified release
[`registry-artifacts`](https://github.com/dahai80/fusion-skills/releases/tag/registry-artifacts),
sha256-verified by consumers on install. The console REST connector flow
(`POST /api/extensions/connectors`) validates the doc, persists it, and
bridges the tools.

## Source

Implementation lives in the `fusion-mlx` module of the fusion monorepo;
connector packaging via `scripts/publish_artifacts.py` in
`fusion-plugins-ecosystem`.
